# Banda Shared Skills

AI skills shared by both implementers and developers. Terminology, glossary, design templates, and common conventions used across Banda Health.

## Installation

### In Cursor

```bash
/add-plugin https://github.com/banda-health/ai-skills shared
```

### Manual Installation

Copy the `skills/` folder to:
- `~/.cursor/skills/` (all projects)
- `.cursor/skills/` (one project)
- `.claude/skills/` (Claude Desktop/Code)

## Available Skills

### Reference Skills

- **`/terminology-banda`**: Banda Health terminology and glossary. Explains common terms used in BandaHealth Go, iDempiere, clinic workflows, and healthcare IT. Use when you need definitions or want to ensure consistent terminology.

- **`/design-document-template`**: Standard template for design documents. Provides a structured outline for specifications, implementation plans, and design decisions.

## Using Skills

Once installed, type the skill name (like `/terminology-banda`) in your AI assistant and follow the prompts.

## For Everyone

These skills are designed for both implementers and developers:
- Clear definitions accessible to non-technical audiences
- Technical depth where needed
- Consistent terminology across teams
